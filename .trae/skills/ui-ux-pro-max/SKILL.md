# UI/UX Pro Max

An AI skill that provides design intelligence for building professional UI/UX across multiple platforms and frameworks.

## Key Features

### Intelligent Design System Generation
The flagship feature is the Design System Generator - an AI-powered reasoning engine that analyzes project requirements and generates a complete, tailored design system in seconds.

## When to Invoke

- User needs UI/UX design guidance
- User asks for design system generation
- User needs UI/UX best practices
- User wants to improve existing UI/UX
- User needs help with responsive design
- User is working on a new UI feature

## How to Use

1. Provide project requirements or context
2. Specify the target platform (Android, iOS, web, etc.)
3. Describe the desired style or mood
4. The skill will generate a tailored design system

## Best Practices

- Always consider accessibility (WCAG AA minimum)
- Use appropriate color contrast
- Implement smooth transitions and animations
- Ensure responsive design across device sizes
- Follow platform-specific design guidelines
